## 描かなかった（見送った）図
- ショットクロック／オーバーアンドバック: ルール43は国際ルールで2026年1月から80秒だが、JLAルールブックは「一部の公式戦にて適用」としており、記事読者が出場・観戦する大会で適用されるか確認できないため図にしていない。
- マンダウンの隊形・クリースまわりの守り方（ゾーン等）: ルールブックに規定がなく、チーム戦術のため公式情報で確認できない。
- 女子フィールド・ドローの並び: 本リポ（関東男子中心）の入門記事での必要性が低い。必要になったら女子ルール13.A（ドロー）をもとに追加する。
