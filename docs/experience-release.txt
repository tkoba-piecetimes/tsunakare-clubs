ラクロスマニア：結果を先頭にしたデザイン更新

変更内容
・スマホの検索・絞り込みを圧縮。初回は男女両方の結果を表示。
・男女と地区は lm-display-v3 に保存。URLでも検索条件を再現。
・大学の略称・かな・英字・表記揺れで検索。候補はクリックと矢印・Enterで選択。
・マイチームの最新結果と次戦をトップに表示。男子・女子は個別保存。
・旧 lm-teams とデモ lm-demo-teams-v2 を読み、lm-favorites-v3 に移行。旧キーは削除しない。
・大学の表記が異なる場合も同じスラッグは同じ識別マークを使用。マークは編集用の略号で、公式校章ではない。
・試合詳細に最新順位、直近5試合、次戦、直接対決を追加。試合当日の順位と誤認させない注記を掲載。
・大学ページの先頭は最新結果と次戦。全結果・過去年度への導線も維持。
・順位表にブロック別の星取表を追加。記事全文・目次・検索と文脈に沿った関連記事を表示。
・記事から存在しないチームページに向いていた3リンクを、その大学の記録検索に修正。
・元データで重複する試合IDには表示用の識別子を追加。既存URLは最終行への割り当てを維持。

本番との接続
既存の pipeline/generate_site.py に統合。毎朝6時のデータ取得、記事生成、静的ページ生成、公開という流れを維持。
試合データを今回のデモ用の日付で固定しない。予定・未掲載の区別には日本時間の当日を使用。
152記事の元原稿・既存URL・canonical・サイトマップ・お問い合わせフォームを保持。
この変更では公開操作・フォーム送信は行っていない。
ローカル確認でアクセス解析のイベントが本番に混ざらないよう、ホスト名を確認。

検証方法
python pipeline/generate_site.py
node --test tests/experience.test.cjs
python tests/validate_site.py
GitHubの変更確認時と本番生成後にも検証を実行。検証に失敗した場合は公開を止める。

公開前の人による確認
選手・保護者・OB/OGに各自のスマホで、次の3つを試してもらう。
1. 自分の大学の最新結果を探す。
2. 次の試合と会場を確認する。
3. 所属リーグの順位を確認する。
各作業の所要時間、迷った箇所、完了できたかを記録し、現行サイトと比較する。
利用者本人によるテストは未実施。代理の実測値や架空の評価を作らない。
本番での表示速度、実機での読み上げ、最新データ取得から公開までの実運用確認は公開判断時に行う。
