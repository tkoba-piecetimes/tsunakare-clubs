## 記事内の要修正（事実誤り・未確認）
1. 【誤り】「2022年3月にJLA主催…全国大会として生まれ変わりました」（本文「中四国地区発の大会が全国大会に」）と FAQ「2022年3月の全国大会化以降」→ 第1回全国大会は **2023年3月**（2022年度）。第4回=2026年3月、第5回=2027年3月と整合。
2. 【不正確】FAQ「基本的には1年生を対象」→ あかつきカップの参加資格は学年ではなく「選手としての会員登録期間が1年未満」（第3回要項）。地区新人戦の資格は地区要項で要確認と書く。姉妹記事 lacrosse-late-join-guide は正しく書いているので食い違っている。
3. 【古い】FAQ「開催時期はおおむね3月上旬」→ 2023年3/16〜18、2024年3/15〜17、2025年3/14〜16、2026年3/6〜8、2027年3/12〜14（広島）。「3月中旬前後」が正確。会場が2027年に岡山から広島に変わることも書く。
4. 【未確認】「男子は中京大学が初優勝…関東・関西地区以外のチームが優勝する初めてのケース」→ JLAの結果ページには「初優勝」の記述がない。第3回の男子優勝は関東（青学・学芸大合同）と確認済み。第1・2回の男子優勝校は未確認。確認できなければ削除するか「中京大学（東海地区）が優勝」にとどめる。女子の「2大会連続」も、第3回は同志社大学単独・第4回は大阪体育大学との合同なので、「同志社大学を含むチームが2大会続けて優勝」と書く。
5. 【欠落】出場枠の「夏冬2回開催の地区は冬季優勝チーム」というルールが本文にない。
