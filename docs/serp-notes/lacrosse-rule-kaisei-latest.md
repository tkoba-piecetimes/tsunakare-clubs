# SERP分析: ラクロス ルール改正 最新（P12）

調査日: 2026-10-22 / slug: lacrosse-rule-kaisei-latest-guide

## 3行要約
1. 上位は日本ラクロス協会（JLA）の公認ルールブック公開ページとPDF（男子2026年度版・女子2026年度版）で、お知らせ文は「公開しました」のみ。どこが変わったかの解説はページ上に無く、PDF内（男子は下線・太字、女子は黄色ハイライト）で確認する形。
2. 国際側は World Lacrosse の男子2025-2027ルールブック（変更箇所の一覧あり）と女子2025-2026ルールブック。ほかは米国NCAAや研究論文が混じり、日本の部員向けに「男女の改正点を現場への影響つきで日本語で整理した記事」はほぼ見当たらない。
3. 差別化: 一次情報（JLA・World Lacrosse）で確認できた改正点だけを、男子・女子に分けて「何が変わったか／現場で何に気をつけるか」で解説する。ショットクロックはJLAが女子で2026年度は適用せず参考掲載、男子は国際ルールとして2026年1月1日施行と記載。リーグ・大会ごとの適用は大会規約の確認が必要、と明記する。
