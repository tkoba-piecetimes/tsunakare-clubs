# SERPメモ: 「ラクロス マウスガード 選び方」

確認日: 2026-09-21（WebSearchで確認）

## 上位表示サイト・関連情報
- 愛媛県歯科医師会「マウスガードの種類」等の歯科医師会・歯科クリニック系コラム: マウスガードの材質・厚さ・既製品/カスタムメイドの一般的な違いを歯科目線で解説。競技別の使い分けには踏み込まない
- inaguma-sika.com「スポーツマウスピースの厚さは競技別で最適化」: 競技別の推奨厚さ（ラクロスは3〜4mm程度）を紹介するが、部活動の予算感・入部タイミングとの結びつきはない
- LAX KONGオンラインストアの既製品マウスピース商品ページ: 商品スペックのみでフィット感の判断基準や色規定の注意点はない
- 日本ラクロス協会（JLA）公式サイト「防具の着用について」: 2017年から男子競技でも着用義務化されたことと、口内のケガ防止・脳振盪予防という目的は明記されているが、既製品/カスタムの選び方や色の規定には触れていない（一次情報として本文で正確に引用する範囲を明確化）
- 海外（World Lacrosse・NFHS等）のルール解説サイト: 女子ラクロスは白色・透明のマウスガード不可、視認しやすい色を求める規定が明確。男子は2026年に米国で色規定が撤廃されたばかりという最新情報もあり、国・団体によって規定が異なる

## 共通点・欠けている要素（3行まとめ）
1. 上位は歯科医師会・歯科クリニックによる一般的なマウスガード解説（材質・厚さ・作り方）が中心で、大学ラクロス部員が「既製品かカスタムメイドか」を予算感・入部タイミングに落とし込んで判断できる記事が見当たらない。
2. 色・見た目の規定（白色・透明の可否）は海外ルールの解説が中心で、日本の大会・リーグごとに規定が異なりうる点、部内やリーグ要項で確認すべきという実務的な注意喚起をしている記事はほぼ不在。JLA公式サイトにも色規定の明記はなく、断定できない領域として扱う必要がある。
3. 「いつ作るべきか」「壊れた・合わなくなったときの対応」「衛生管理」など、シーズンを通じた運用面まで踏み込んだ記事が薄い。

## 差別化方針（このサイトでの実装）
- JLA公式サイト「防具の着用について」（`lacrosse.gr.jp/medicalscience/armor/`）を一次情報として2017年の男子義務化・目的（口内保護＋脳振盪予防）を正確に引用する。色規定はJLA一次情報に明記がないため「大会・リーグ要項や部内で必ず確認する」という実務的な注意喚起にとどめ、断定しない。
- 既製品/カスタムメイドの違いは歯科医療分野の一般的な解説を参照しつつ、「新入部員がまず既製品で慣れて、通しで使うならカスタムメイドに移行する」という段階的な判断軸を提示する（先行記事にない切り口）。
- 費用相場は歯科医院によって幅が大きい（数千円〜数万円）という実態を正直に示し、単一の断定的な金額を書かない。
- 既存記事「ラクロス防具の選び方」（`lacrosse-protective-gear-guide.md`）はマウスガードを防具一式の一部として短く触れる程度のため、本記事はマウスガード単体に特化して深掘りし、相互リンクでカニバりを避ける。
- 一次データページへの内部リンクとして `/teams/`（所属チームのリーグ・対戦相手を確認する起点）と `/standings/`（所属リーグの対戦の激しさの目安）を文脈に沿って配置。
