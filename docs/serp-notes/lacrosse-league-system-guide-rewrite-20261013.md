## 原典確認（2026年度 JLA 実施概要）
- 関東 https://www.lacrosse.gr.jp/news/59526/ : 男子1〜3部約37チーム・女子1〜4部約56チーム。男子1〜3部・女子1〜2部は2ブロック制、女子3〜4部は2〜3ブロック。男女1部各ブロック上位2が決勝T（準決勝=1位対他ブロック2位）。入替戦=上位ブロック5・6位 対 下位ブロック1・2位（抽選）。順位は大会規約に基づく。
- 関西 https://www.lacrosse.gr.jp/news/61159/ : 男子1部7・2部7・3部3、女子1部7・2部7・3部10（2ブロック）。1部1〜3位で決勝T（準決勝=2位対3位、決勝=1位対勝者）。入替戦=5位対3位・6位対2位・7位対1位。
- 東海 https://www.lacrosse.gr.jp/news/61254/ : 男子1部6・2部4、女子1部7・2部（A4・B6）。決勝T=1部1〜3位＋（1部4位 対 2部1位）の勝者。入替戦=男子は1部下位2 対 2部上位2、女子は1部下位3 対 2部上位2。自動昇降格あり。
