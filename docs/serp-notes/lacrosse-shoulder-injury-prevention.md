# SERPメモ: ラクロス 肩 怪我 予防（2026-11-24）

KW在庫(P)の全項目が既存記事で制作済みだったため、既存の怪我予防シリーズ（突き指・足首・肉離れ・膝ACL・腰痛・脳震盪・熱中症）に欠けていた「肩」を新規KWとして採用。

## 上位の顔ぶれ（WebSearch「ラクロス 肩 肘 怪我 予防」）
- 野球肩・野球肘の解説（ザムスト、整形外科クリニック等）が中心。ラクロス固有の肩の記事はほぼ無い
- ラクロスの怪我一般（整骨院サイト、lacrosse-plus）は部位別割合の紹介が中心で肩に特化しない
- 海外は論文（NCAA男子の肩損傷、救急外来データ）と小児医療機関の注意書き

## 共通点（検索意図の正解）
- 怪我の種類、受診の目安、予防の一般論

## 欠けている要素（差別化点）
1. 接触外傷と使いすぎの2タイプに分けた整理、国内データに肩が出ない点の明示
2. 復帰を状態で判断する段階表と、部の運用（申告・復帰基準・接触後確認）
3. サイト内の怪我予防シリーズ・順位表・日程ページへの内部リンク
