## 事実確認で見つかった問題（即時訂正の対象）
- L13「女子は12人で編成されます」は誤り。日本ラクロス協会の競技ルールページは「女子ラクロス（10人制）」と記載（2026-10-03 mens-womens-lacrosse 診断で確認済み、同記事は10人制に訂正済み）。九大ガイドも旧ルールが12人と記載。姉妹記事と矛盾している
- L13「2019年のルール改正前は20分×2クォーター制」は出典が確認できない（九大ガイドの旧ルールは女子の25分ハーフ）。JLA公認ルールブックで確認できなければ削除
