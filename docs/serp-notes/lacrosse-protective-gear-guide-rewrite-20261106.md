## 自記事に足りない要素
1. タイトルで「サイズ選びのコツ」と言いながら、サイズの測り方（頭囲・手のサイズ）とフィット確認の手順が本文にほぼない。上位の英語ガイドはここを具体的に書いている。
2. ルール上の着用義務（何が必須で何が任意か）が曖昧。JLA公認競技ルール2026年度版では、男子は全選手にグローブ・適切な靴・フェイスマスクと両側を留めるチンストラップ付きヘルメット・マウスガード（上顎の歯を全て覆うもの。市販の成形タイプ／歯科で調整／歯科で製作のいずれか）、女子フィールド選手はアイガード必須・ヘッドギアとフェイスマスクは着用不可・グローブとノーズガードは着用可、マウスガードは上あごの全ての歯を覆う専門的に製造されたもの。
3. グローブの指を切ってはならない（手のひらは切ってもよい）、男子ゴーリーはスロート・チェストパッド・ファウルカップが着用義務、という条文レベルの情報。
4. 既存の詳しい記事（マウスガード・指のケガ・ゴーリー）への導線。
