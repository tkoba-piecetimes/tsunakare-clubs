# KW在庫と編集戦略（ラクロスマニア）

策定日: 2026-09-10（木場さん決定「全オウンドメディア月100本体制。部活メディアは上位クエリを狙いつつ、部員が見に来る場所という地位を確立する」に基づく）

対象: 大学ラクロス情報メディア「ラクロスマニア」（SITE_BASE: https://lacrossemania.jp/ 、独自ドメイン接続済み。リポジトリは `tsunakare-clubs`／`tkoba-piecetimes/tsunakare-clubs`）

前提: JLA公開スプレッドシートから試合日程・結果・星取表を取得する8地区×男女のリーグ戦データベース型サイト（2023〜2025年度データ、2026年度は全地区展開済み）。既存記事は「戦術」「練習」「キャリア」「資金調達」「就活」「大会ガイド」「基礎知識」「進路」「チーム運営」「分析」を既にかなり厚くカバー済み（`clear-basics`/`faceoff-training`/`man-down-defense`等の戦術系、`lacrosse-rules-guide`/`mens-womens-lacrosse`等の基礎知識系、`lacrosse-club-job-hunting*`等の就活系、`lacrosse-alumni-career`等のキャリア系）。加えて`review-*`（週次結果まとめ、自動性の強い定型記事・8地区分）・`season-*`（大学別シーズン記録、現状は2023年関東男子のみ）が自動生成に近い形で多数存在する。本ドキュメントはその上に積み増す新規KWの在庫。記事は3,000字以上、H2から開始、frontmatterは`title`/`description`/`category`/`date`/`cta`の5項目のみ（`bukatsu-seo-article` SKILL.md準拠）。

一次データページのURL構造（内部リンク先）: `/<league>/`（リーグトップ、例: `/kanto-m/`）・`/<league>/schedule/`（日程）・`/<league>/clubs/<slug>/`（チームページ）・`/<league>/matches/<id>/`（試合ページ）・`/standings/`（順位表）・`/records/`（記録室）・`/teams/`（チーム一覧）・`/glossary/`（用語集ページ、既存）・`/videos/`（動画インデックス）・`/articles/<slug>/`

## 1. 戦略メモ：部員が検索する10の場面

1. 高校生・保護者が「大学ラクロス 強豪」「大学から未経験で始められるか」を検索する（既存記事群あり）
2. 受験生が「ラクロス 推薦」「部活選びのポイント」を検索する（既存記事あり）
3. 新入部員が用具（スティック・防具）の選び方・値段・初期費用を検索する
4. 現役部員が自分のポジション（アタック・ディフェンス・ゴーリー・ミッドフィルダー）の役割や練習法を検索する（一部は戦術記事でカバー）
5. 現役部員が怪我予防（突き指・脳震盪等）・体幹トレーニング・栄養管理を検索する
6. 部の運営担当（渉外・主将）が部費・遠征費・スポンサー探しの実務を検索する（既存記事あり）
7. マネージャー・学生コーチが自分の仕事内容・キャリアへの活かし方を検索する（一部キャリア記事あり）
8. OB/OGが引退後のキャリア・チームワーク経験の評価のされ方を検索する（既存記事群あり）
9. ファン・保護者・他大学の部員がリーグ戦・全日本大学選手権の日程・結果・観戦方法を検索する（既存記事＋自動更新記事あり）
10. 就活を控えた部員がガクチカ・ES・就活スケジュールを検索する（既存記事群が非常に厚い）

**3層で面を作る方針**:
- **H（上位クエリ）**: 大学名×強豪、日本代表輩出、大会名（全日本大学選手権）、用具（スティック・防具）の値段、初心者向け、就職先。自サイトが持つ8地区×男女の一次データ（順位表・チームページ・記録室）と組み合わせて差別化する。更新型は年1回リライト
- **P（部員向け定番）**: 用具の選び方・怪我予防・栄養・用語・新歓/引退・マネージャー/学生コーチ・ポジション別練習など、部員の日常的な悩みに答えるロングテール本体。既に戦術・キャリア・就活は厚いため、用具・怪我・栄養・用語のカバーを優先する
- **K（企画）**: 自サイトが持つ一次データ（8地区×男女の順位表・試合結果、2023〜2025年度データ）を横断集計したランキング・まとめ企画。既存の`review-*`（週次結果、自動）・`season-*`（大学別シーズン記録、自動）と同じ内容を並べ直すだけの記事は作らない

## 5. 運用メモ

- **月ごとの制作配分の目安**（このサイト単体）: 月4〜6本を目安に、H:P:K = 2:3:1 程度の比率で配分。既存の`review-*`（週次自動更新）・`season-*`（シーズン記録）と並走させ、企画記事はオフシーズン（リーグ戦が少ない時期）に厚めに配分する
- **1記事1意図**: H1/H2、H3/H12、H5/H18、H9/H21のように同義・近接クエリは統合する。特にH5は「大学生代表」という誤った前提を避け、K7の輩出実績切り口に一本化する
- **90日表示ゼロは統合・削除**: GA4で公開90日後に表示0のロングテール記事は近接テーマへ統合するか`content/articles/`から削除する
- **更新型記事は年1回リライト**: H1〜H4/H12（強豪校ランキング）、H6（全日本大学選手権結果）、K1/K12/K13/K14/K17（自サイト集計データ系）はシーズン終了後（11〜12月頃）に当年データへ更新
- **先行競合への対応**: lacrosse-plus.netが強豪校ランキング・地区別特集で既に一定の網羅性を持つ。同じ切り口の薄い記事では勝てないため、必ず自サイトの一次データ（8地区×男女・2023〜2025年度の実試合結果）を根拠に添え、他サイトにない独自集計であることを明示する

**SERP確認済（2026-09-10 WebSearchで確認、上位5クエリ）**:
- H1「大学 ラクロス 強豪」: spaia.jp・lacrosse-plus.netという専門サイトが既に強い。自サイトの実データ集計での差別化が必須 → 採用（差別化条件付き）
- H7「ラクロス 大学から 未経験」: 九州大学図書館ガイド等の一次情報が中心で、不安解消に特化した記事が薄い → 採用
- H9「ラクロス スティック 値段」: LAX KONG・メルカリ等のECサイトのみでポジション別ガイドが不在 → 採用
- H5「ラクロス日本代表 大学」: **日本代表は大学生ではなく社会人選手が中心という実態が判明**。誤った前提（現役大学生代表という切り口）を避け、輩出実績（K7）に絞る運用ルールを追加
- P11「ラクロス 用語集」: 上位はDTIの個人サイト（古い形式）・Weblio・大学部活サイトの断片的な用語集で、モダンで包括的な用語集が不在 → 採用（強い勝ち筋）
