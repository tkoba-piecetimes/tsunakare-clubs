基礎スキル 2026-10-26

ラクロス部 新入生の練習メニュー｜入部後3か月の流れと基礎の順番

はじめての方向け

この記事の内容入部後の練習は「道具に慣れる→基礎を固める→対人に入る」の順で考える

「ラクロス部に入ったら、最初の数か月は何をするのだろう」「スティックボールを運ぶ・パスする・シュートするために使う、先に網が付いた棒状の道具。ボールは手で直接持てない。用語辞典で見るを持ったことがないのに、練習についていけるだろうか」。大学からラクロスを始める新入生が、入部前後に抱きやすい疑問です。ラクロスは大学から始める人が多い競技で、たとえば京都大学の広報誌『紅萠』では、男子ラクロス部の新入部員について「ほとんどがラクロス初心者」と紹介されています（出典は記事末尾）。未経験で入ること自体は、珍しいことではありません。

この記事では、新入生が最初に取り組むことの多い練習を、「全体の流れ」「1回の練習の組み立て」「基礎メニューの順番」「自主練の置き方」「新人戦までの道筋」「休む判断」に分けて整理します。部ごとの練習内容は指導者や環境によって大きく異なるため、ここで示す流れはあくまで一般的な例です。実際のメニューは、所属する部の指導者や上級生の指示を優先してください。個別の技術は、すでに詳しく扱っている記事へリンクしています。

入部後の練習は「道具に慣れる→基礎を固める→対人に入る」の順で考える

新入生の練習は、部によって細部は違っても、おおむね次のような順番で組まれることが多いと考えられます。以下は編集部が一般的な構成として整理した例で、期間や内容を保証するものではありません。

段階目安の時期主な内容意識したいこと
1. 道具と動きに慣れる入部直後〜1か月スティックの持ち方、クレードルクロスを小刻みに揺らし、ボールを網のくぼみに保ったまま相手から守る動き。用語辞典で見る、壁当て壁に向かってボールを投げ、跳ね返りを受ける、一人でできる基礎練習。用語辞典で見る、軽いランニングボールとスティックの感覚をつかむ。疲労をためすぎない
2. 基礎を固める1〜2か月目キャッチ・スロー、グラウンドボール地面に転がっているボール、またはそれを拾い合うプレー。先に確保したほうが攻撃できる。用語辞典で見る、2人組のパス同じ動きを繰り返し、フォームのばらつきを減らす
3. 動きの中で使う2〜3か月目走りながらのパス、簡単な対人、ポジションの基本基礎が崩れたら、一つ前の段階に戻って確認する
4. 試合形式に触れる部の方針による練習試合、新人戦に向けた練習役割と約束事を覚える。結果より経験を重ねる

大切なのは、前の段階が完全にできてから次へ進むのではなく、行き来しながら進めることです。対人練習で投げるフォームが崩れたと感じたら、壁当てに戻って確かめる、といった使い方が現実的です。シーズン全体の中で新入生の時期をどう位置づけるかは、運営側の視点になりますが練習計画の立て方で整理しています。

1回の練習はこう組み立てられることが多い

練習時間や頻度は部によってまちまちです。平日の夕方に活動する部もあれば、朝練中心の部もあります。そのため、ここでは時間配分の数字ではなく、1回の練習の「流れ」だけを示します。

1. ウォームアップと体の準備

ランニングや動的なストレッチ、関節を動かす運動で体を温めます。ここを省くと、後半の基礎練習で動きが硬くなりやすく、けがにもつながる可能性があります。新入生はまず「何のために行う運動か」を上級生に聞きながら覚えていくと、自主練にも応用できます。

2. スティックワーク（クレードル・壁当て・2人組パス）

練習の最初の山場です。クレードルはスティックを揺らしてボールを保持する動作で、キャッチ後やスローの前に行います。ラクロスプラスに掲載されているポール・ラビル氏の基礎練習の解説では、シュート・キャッチ・スロー・グラウンドボール・クレードルの5つが基本スキルとして扱われています。入部直後の新入生は、この5つのうち、クレードル・キャッチ・スローから触れることが多いでしょう。

3. グラウンドボール

地面に転がったボールを、すくい上げて保持する動作です。ラクロス.comの初心者向け解説では、グラウンドボールは試合で優位に立つための重要な基本動作として位置づけられています。ボールの保持を左右する場面が多いため、基礎の段階から繰り返し行われやすい練習です。姿勢は、膝を曲げて低くする、という説明が一般的です。

4. 対人・ゲーム形式と、クールダウン

基礎が整ってきたら、少人数のゲーム形式に入る部もあります。最後にクールダウンとストレッチを行い、疲労をためないようにします。新入生の間は、練習の終わりに「今日できたこと・できなかったこと」を一言でメモしておくと、翌週の自主練の材料になります。

基礎メニューの順番と、それぞれの役割

壁当て：最初に身につけたい自主練

壁当ては、壁にボールを投げて跳ね返りを受ける練習です。GRASPOの解説では、パス・キャッチの技術向上においても「最も効率が良く、効果的」な方法と紹介されています。メニューとして、初級は「通常のパスキャッチ」「片手パスキャッチ」「クイックパス」、上級は「ビハインドパス」「アラウンド・ザ・パス」が挙げられています。入部直後は初級の通常のパスキャッチだけで十分です。

時間の目安については、ラクロス.comの初心者向け解説で、5〜10分程度の壁当てが紹介されています。長く行うより、短い時間でも継続するほうが続けやすいという考え方です。GRASPOの解説でも、遊び感覚で継続することが推奨されています。ただし、疲れてフォームが崩れてきたら、その日は切り上げるのが無理のない進め方です。フォームの直し方は、キャッチのコツとスローのコツで、症状別に整理しています。

クレードル：握り込まないことが前提

ラクロスプラスに掲載されているポール・ラビル氏の解説では、クレードルは手首の動きから始め、慣れたら肘の動きを加える方法が紹介されています。力を入れて握り込みすぎないことが前提です。握り込みやすい人は、壁当ての途中に軽くクレードルを挟み、手の力が入りすぎていないか確認してみてください。

グラウンドボール：姿勢と手の使い方を覚える

先ほど触れたとおり、グラウンドボールは低い姿勢で行う動作です。ボールに向かって勢いよく走り込むと、すくい損ねたり、相手と接触したりする場合があります。新入生の間は、まず止まった状態で姿勢と手の使い方を確認し、慣れてから動きを加えていく順番が、一般的には取り組みやすいと考えられます。用語に迷ったら、ラクロス用語集の決定版やサイト内の用語集で確認できます。

体力づくりは「練習を続けるための土台」として位置づける

ラクロスは走る時間の長い競技です。ただし、入部直後から高い負荷の筋力トレーニングを自己流で始めると、フォームが崩れたり痛みが出たりする場合があります。筋トレや体幹トレーニングは、チームのメニューに沿って始め、自分で追加するときは回数を抑えて少しずつ増やすのが現実的です。

具体的な種目と頻度は、筋トレメニューと体幹トレーニングのメニューにまとめています。食事や補食の考え方は食事・栄養管理も参考にしてください。

自主練は「短く・毎回同じ形」で置く

チーム練習の回数に限りがある場合、自主練は上達の助けになります。ここでは、先に紹介した壁当ての時間の目安をもとに、編集部が例として整理した置き方を示します。効果を保証するものではなく、体調や授業の都合に合わせて調整してください。

  • ウォームアップのあとに壁当てを5〜10分: 通常のパスキャッチだけを行い、一点に返ってくるかを確認します
  • やることを1つに絞る: 「今日は足の踏み出しだけ」のように、見直す点を1つに絞ると原因を切り分けやすくなります
  • 練習後に一言メモ: できたこと・できなかったことをスマホのメモに残し、翌週に見返します
  • 痛みや違和感があれば休む: 指先や手首に負担がかかりやすいため、突き指の予防も確認してください

授業やアルバイトとの両立が不安な人は、時間の使い方を単位との両立の記事で整理しています。

新人戦への道筋：1年生が最初に目指しやすい公式戦

大学ラクロスには、1年生が中心となって戦う「新人戦」があります。時期や形式は地区によって異なります。全国大会にあたる「ラクロス全日本学生新人選手権大会（あかつきカップ）」は、日本ラクロス協会（JLA）主催で、第4回は2026年3月6日から8日にかけて岡山県美作市で開催され、男女各8チームが出場しました。出場できるのは、その年の1年生を中心としたチームです。

新入生にとっては、「新人戦に出ること」そのものを目標にする必要はありません。ただ、入部後の練習が、どこへつながるのかを知っておくと、日々の基礎練習の意味が見えやすくなります。新人戦の仕組みや出場枠は、新人戦とあかつきカップの解説にまとめています。

自分の大学が属するリーグの日程や結果は、本サイトの関東男子の試合日程、関東男子の順位表、全国8地区のチーム一覧で確認できます。他大学の上級生の試合を観戦して、パスの出し方やグラウンドボールの場面を見ておくのも、手がかりになります。観戦のしかたは初めての観戦ガイドも参考にしてください。

休む・止める判断：暑さ・頭部・指のけが

新入生は、疲れや違和感を「自分が慣れていないだけ」と考えて我慢しがちです。次のような場合は、無理をせず、上級生や指導者に伝えて休んでください。

  • 暑さ: 夏場の練習は熱中症のリスクが高まります。日本スポーツ協会（JSPO）は、暑さ指数（WBGT）に応じた運動の目安として「熱中症予防運動指針」を公表しています。水分補給と休憩の取り方は、部のルールと合わせて確認してください
  • 頭部への衝撃: 頭を打った、ぼんやりするなどの場合は、練習を続けず、早めに状況を伝えます。詳しくは脳震盪のリスクと予防にまとめています
  • 指・手首の痛み: 突き指や手首の痛みを放置して壁当てを続けると、悪化する場合があります
  • 用具: マウスピースやプロテクターなどの用具が合わないと、練習のたびに負担がかかる場合があります。マウスピースの選び方や防具の選び方も参考になります

なお、本記事はけがや熱中症の診断・治療を示すものではありません。症状が続く場合は、医療機関を受診してください。

入部前に確認しておきたいこと

練習内容は部によって異なるため、入部前の見学や体験で、次の点を聞いておくと、入部後のずれが小さくなります。

  1. 新入生向けに、最初の1か月はどんなメニューが組まれているか
  2. 練習の日程と時間帯、授業やアルバイトとの両立についての考え方
  3. 道具の貸し出しや購入の流れ（スティックの価格の目安やポジション別の選び方も参考になります）
  4. 休むときの連絡方法と、試験期間などの扱い
  5. 新人戦など、1年生が出場する公式戦の有無

部の選び方全体は部活選びで見るべきポイントと、セレクションの有無の記事で扱っています。

よくある疑問

スティックを持ったことがなくても、練習についていけますか

大学から始める人が多い競技のため、基礎から教える部も少なくありません。ただし、どのくらい丁寧に教えるかは部によって異なります。見学や体験で、新入生向けのメニューがあるかを確認すると安心です。

自主練は毎日したほうがよいですか

GRASPOの解説では毎日の継続が推奨されていますが、体の状態や授業の都合は人によって違います。短い時間でも、無理のない頻度で続けることを優先してください。

女子の部員でも同じ流れですか

基本のスティックワークは共通する部分が多い一方で、ルールや用具の違いがあります。違いは男子と女子のラクロスの違いで整理しています。

まとめ

  • 入部後の練習は、道具に慣れる、基礎を固める、動きの中で使う、試合形式に触れる、という順番で考えると整理しやすい
  • 1回の練習は、ウォームアップ、スティックワーク、グラウンドボール、対人、クールダウンの流れで組まれることが多い
  • 壁当ては5〜10分でも続けやすい自主練。やることは1つに絞ると原因を切り分けやすい
  • 体力づくりは、チームのメニューに沿って少しずつ。自己流の追加は回数を抑える
  • 新人戦は1年生が最初に目指しやすい公式戦。日程と形式は地区ごとに異なる
  • 暑さ・頭部・指の痛みなどは、我慢せずに早めに伝える

練習メニューの細部は部によって異なります。最終的には、所属する部の指導者と上級生の指示に従ってください。
