ラクロスシューズ（スパイク）の選び方｜ルール・グラウンド・カット高の判断軸

この記事の内容まず確認したい、ルールブックに書かれている靴の規定ラクロス専用シューズとほかの競技用の違いグラウンドとスタッドの相性を考えるローカットかミッドカットかサイズ選びと試着のポイント値段や買い方の考え方手入れと買い替えの目安試合結果と見比べて、自分のチームの環境を知るまとめ出典

スティックボールを運ぶ・パスする・シュートするために使う、先に網が付いた棒状の道具。ボールは手で直接持てない。用語辞典で見るや防具の購入計画は立てたのに、シューズは「サッカー用や普段のスニーカーで間に合うだろう」と後回しにしている新入部員は少なくありません。ところがラクロスは、急な方向転換、グラウンドボール地面に転がっているボール、またはそれを拾い合うプレー。先に確保したほうが攻撃できる。用語辞典で見るの競り合い、接触を伴う守備など、足元に負荷がかかる場面が多い競技です。シューズ選びは、プレーのしやすさだけでなく足首やひざのケガの予防にも関わります。ここでは、JLA（日本ラクロス協会）のルールブックに書かれている靴の規定を出発点に、グラウンドとの相性、カット（足首まわりの高さ）の違い、サイズ選びと手入れまでを順に整理します。

まず確認したい、ルールブックに書かれている靴の規定

シューズを選ぶ前に、ルールで何が決まっているかを押さえておきましょう。JLAが公開している公式ルールブックは、男子と女子で記述が異なります。

  • 女子（2026年版）: 選手は、プラスチック、金属、革、またはゴム製のクリート／スタッド（靴底の突起）がついたシューズを着用できるとされています。一方で、陸上競技用のスパイクは認められません。また、構成に関わらず、すべてのクリート／スタッドの露出面は平滑でなければならないと定められており、フラットソール（突起のない靴底）のシューズを着用することもできるとされています。
  • 男子（2025年版）: 全ての選手は保護用のグローブ、適切な靴、フェイスマスク、チンストラップ付きのヘルメットを着用しなければならない、という記述になっています。「適切な靴」の具体的な材質やスタッドの仕様までは、このルールブックの該当箇所では示されていません。

つまり、女子については「陸上用スパイクは不可」「突起の露出面は平滑」といった具体的な条件がありますが、男子は「適切な靴」という書き方にとどまります。ここで大事なのは、ルールブックに書かれていないことを「何を履いても良い」と読まないことです。実際の可否は、試合前に審判員が用具を点検する運用（ルールブックには、試合前にシューズを含む装具がルールに適合しているか点検するという趣旨の記載があります）と、各リーグ・各大会の要項、各チームのグラウンド使用ルールによっても左右されます。購入前に、所属リーグの要項と練習場所の使用条件を、キャプテンや先輩に確認しておくと安心です。

なお、この記事で扱うのは2026年11月時点で確認できたJLAのルールブック（女子は2026年版、男子は2025年版）の内容です。年度が変わると記述が改定される場合があるため、買い替えのタイミングでは最新版を見直してください。

ラクロス専用シューズとほかの競技用の違い

ラクロス用として売られているシューズは、米国のメーカーや専門店が多くの解説を出しています。その内容によると、ラクロス専用モデルには次のような特徴があるとされています。

  • つま先まわりの補強があり、グラウンドボールの競り合いやフェイスオフ男子の試合開始や得点後に、センターで2人が向かい合ってボールを奪い合う再開方法。用語辞典で見る（ボールの奪い合いで始まる場面）に対応しやすい
  • 横方向の動きを支える作りで、切り返しの多い動きに合わせている
  • スタッドの配置が、ラクロスの動きを想定して最適化されている

これに対して、サッカー用のスパイクは、つま先側にスタッドがなく、足首のサポートも少ない設計のものが多いため、接触を伴うプレーでは負担が大きくなる可能性があると、米国の専門店の解説では指摘されています（出典は本記事末尾の一覧を参照）。ただし、これは主に米国の販売店による解説であり、日本のラクロス部で「サッカー用で代用してよいか」を直接検証した一次情報は、今回の調査では見つかりませんでした。

日本国内でも、サッカー用のスパイクで競技を始める部員はいます。代用すること自体を一概に否定する根拠はありませんが、ルールの項目で触れた「陸上用スパイクは女子で不可」という規定や、接触の多い局面での負担を考えると、継続して競技を続ける見込みがあるなら、ラクロスでの使用を想定した靴を選ぶ価値があります。入部直後でまだ続けるか決めきれないときは、まず先輩に履いているものを聞き、練習で使える範囲の靴から始めるのも一つの考え方です。

グラウンドとスタッドの相性を考える

次に重要なのが、練習や試合で使うグラウンドの種類です。靴底の突起（スタッド）の形や素材は、天然芝・人工芝・土のグラウンドで向き不向きが分かれます。

スパイクのソール表記については、サッカー用の一般的な分類が参考になります。たとえば、FGは天然芝向けで本数が少なく細長いスタッド、HGは乾いて硬い土向けで短めの丸型や円錐型、AGは人工芝向けで短めで丸く中空のスタッド、TFはゴム素材の底で摩耗した人工芝や練習用に使われる、といった整理が紹介されています。これはサッカーの解説ですが、「グラウンドに合わないスパイクを履くと、靴が傷む、滑る、引っかかって捻挫につながる場合がある」という指摘は、ラクロスの靴選びにも共通して当てはまります。

ラクロス専用品については、米国の専門店の解説で、ゴムやプラスチックのスタッドが靴底に固定された「モールドタイプ」が、天然芝と人工芝の両方で使える汎用的な選択肢として紹介されています。短くて数の多いスタッドは、やわらかい芝に深く食い込みすぎず、安定したグリップを保ちやすいという説明です。一方、取り外し式のスタッドについては、リーグや施設によって使用が制限される場合があるともされています。

実際の選び方の流れは次のとおりです。

  1. 自分のチームの練習場所（天然芝、人工芝、土、体育館など）と、公式戦の会場の路面を確認する
  2. 練習で最も使う路面を基準に、ソールのタイプを決める
  3. 公式戦の会場が練習と違う路面なら、その路面で使えるかをチームに確認する
  4. 平日は人工芝、週末は天然芝というように路面が混在する場合は、両方で使いやすいモールドタイプを軸に検討する

どの大学がどのリーグで戦っているかを知りたいときは、全国8地区のチーム一覧やリーグ別の日程から、自分のチームの属するリーグと試合会場の傾向を確認できます。練習試合や遠征が多いチームは、会場の路面もあらかじめ確認しておくと、買い直しを避けられます。

ローカットかミッドカットか

シューズ選びで迷いやすいのが、足首まわりの高さ（カット）です。米国の専門店の解説では、次のように整理されています。

  • ミッドカット: 足首まわりを支えて安定性を高め、滑りやすい場面や凹凸のある地面での捻挫を防ぐ助けになるとされる。踏み込んで押し込む動きが多いディフェンス主に自陣のゴール近くで、相手のシュートを防ぎボールを奪う選手。男子は3人。用語辞典で見るに向くという紹介がある
  • ローカット: 足首の可動域が広く、軽量。スピードを重視するアタック主に相手ゴールの近くで、シュートや得点の組み立てを担う選手。男子は3人。用語辞典で見るやミッドフィルダー攻めと守りの両方に関わり、コート全体を動く選手。男子は3人。用語辞典で見るに好まれる傾向がある

ただし、「ミッドカットを選べば捻挫を防げる」とは言い切れません。一般向けの医療・スポーツ解説では、ハイカット（足首を覆う靴）が必ずしも捻挫予防にならない可能性が指摘されています。安定性の面では効果があるとする見方がある一方で、動き出すと足首まわりの筋肉の反応のタイミングが遅れる可能性や、跳躍の高さが下がる可能性も報告されているためです。これらは主に米国などでの一般的な研究の紹介であり、ラクロス部員を対象に検証したものではありません。

そのため、判断軸は「ポジション」より、自分の足の状態に置いたほうが安全です。

  • 過去に足首の捻挫をくり返している人は、靴のカットだけで解決しようとせず、サポーターやテーピング、筋力トレーニングも含めた対策を検討する（ラクロスの足首捻挫の予防ガイドで整理しています）
  • 診断を受けたことがある場合は、医師や理学療法士、チームのトレーナーに靴のカットの選び方を相談する
  • ケガの履歴がない場合も、実際に試着して、走る・止まる・切り返す動きで足首まわりが窮屈でないかを確かめる

ポジション別の目安は参考にとどめ、最終的には「自分が動きやすく、不安なく踏み込める靴」を基準にするのが現実的です。

サイズ選びと試着のポイント

シューズは、サイズが合わないとケガと直結します。次の点に気をつけましょう。

  • 試合や練習で履く靴下と一緒に試着する。薄手のソックスで試着して、実際には厚手の靴下を重ねるとサイズ感が変わります
  • 夕方の足がむくんだ時間帯に試着する。長時間の練習や試合では足がむくみやすく、朝に合っていた靴が窮屈になる場合があります
  • つま先に余裕があるか、かかとが浮かないかを確認する。急停止でつま先が当たると爪や指先のトラブルにつながります
  • 店内で小走りや横の動きを試す。可能なら、店のスペースで軽く切り返してみて、足が靴の中で動きすぎないかを確かめます
  • クッション性と通気性。長時間の練習が続く時期は靴擦れが起きやすく、米国の専門店の解説でも、長時間履いても靴擦れしにくい靴を選ぶよう勧められています

また、新品の靴をいきなり公式戦で使うと、靴擦れや違和感が出るおそれがあります。練習で数回履いてなじませてから試合に使うようにすると、当日のトラブルを避けやすくなります。成長期の高校生が大学入学前に買う場合は、足のサイズが変わる可能性も考えて、入部後に先輩の意見を聞いてから購入するのもよいでしょう。

値段や買い方の考え方

ラクロス専用シューズの価格は、メーカー、モデル、販売店によって幅があります。この記事では、確かな一次情報で価格帯を確認できていないため、具体的な金額は示しません。購入先の目安として、ラクロス専門店、スポーツ用品店、各メーカーの公式通販などがあり、モデルによって取り扱いの有無が異なります。主要メーカーの取扱品目の整理はラクロス用品メーカー比較にまとめているので、あわせて確認してください。

予算に限りがある新入部員が考えたいのは、次の優先順位です。

  1. まず安全に関わるもの（ヘルメット・マウスガード歯と口の中を守るために口にはめる防具。男子は2017年から全員の着用が義務になった。用語辞典で見る・グローブなど）を優先する。防具全体の考え方はラクロス防具の選び方で整理しています
  2. シューズは、使うグラウンドに合い、サイズが合うものを最優先にする。見た目やブランドは後回しにする
  3. 初期費用の全体像は、スティックの項目とあわせてラクロススティックの値段と初期費用の目安で確認する
  4. 部としての費用負担や資金面は、部費と資金調達の考え方を参考にする

古い靴の中古を先輩から譲り受ける選択肢もありますが、足の形や歩き方には個人差があり、ソールがすり減った靴はグリップが落ちている場合があります。譲り受ける場合は、ソールの減り、スタッドの欠け、インソールのへたりを確認してから使いましょう。

手入れと買い替えの目安

シューズは、手入れ次第で使える期間が変わります。

  • 使用後は泥や砂を落とす。人工芝のゴムチップや土は、靴底の隙間に残りやすいためです
  • 濡れたら新聞紙などを入れて陰干しする。直射日光やドライヤーの熱は、素材を傷める場合があるので避けます
  • スタッドの減りと欠けを定期的に確認する。スタッドが丸くすり減ると、グリップが落ちて滑りやすくなります
  • ソールの剥がれや、アッパー（甲の部分）の破れを見つけたら早めに交換を検討する
  • 遠征や合宿ではシューズを2足用意する。連日の試合で片方が乾かない場合に備えられます（持ち物全般は遠征の持ち物リストも参考になります）

部で用具をまとめて管理している場合は、シューズの保管場所や乾燥の方法について、用具管理の考え方も確認しておくとよいでしょう。

試合結果と見比べて、自分のチームの環境を知る

用具選びは、自分のチームがどんな環境で戦うかを知ることから始まります。所属リーグによって試合会場や遠征の有無が異なるため、路面の確認はチームごとに行う必要があります。リーグごとの順位や星取りは全国8地区の順位表で、これまでの対戦結果や記録は記録室で確認できます。自分のチームの試合会場と練習場所の傾向を把握したうえで、シューズを選ぶと、買ってからの後悔が減ります。

まとめ

ラクロスのシューズ選びで押さえたいポイントは、次の5つです。

  1. ルールを確認する。女子は陸上用スパイク不可でスタッドの露出面は平滑、男子は「適切な靴」とされています。可否は試合前の点検や大会要項でも左右されるため、先輩に確認する
  2. 使うグラウンドに合わせる。練習の中心となる路面を基準に、ソールのタイプを決める
  3. カットは自分の足の状態で決める。ミッドカットが必ず捻挫を防ぐとは言えず、ポジションの目安は参考程度にとどめる
  4. サイズは実際の靴下を履き、夕方に試着する。新品は練習でなじませてから試合で使う
  5. 手入れと点検を習慣にする。スタッドの減りやソールの傷みは、早めの交換につなげる

シューズは目立たない用具ですが、足元の安定は、切り返しや競り合いといったラクロス特有の動きの土台になります。無理のない予算の範囲で、自分のチームの環境と自分の足に合う一足を選びましょう。
