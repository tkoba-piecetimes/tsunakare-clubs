学生生活 2026-11-04

ラクロス部の試合・遠征で授業を休むとき｜公欠の確認と欠席対応の進め方

この記事の内容まず知っておきたい：「公欠」は大学や事由によって扱いが違う

リーグ戦の試合日が決まり、遠征の予定も見えてきたとき、部員が次に気になるのは「その日の授業はどうなるのか」ではないでしょうか。「試合だから公欠になるはず」と思い込んでいたら、実際には通常の欠席扱いだった、という行き違いは起こり得ます。

この記事では、試合・遠征・合宿で授業を休むことになったとき、何を・いつ・誰に確認し、どう動くかに絞って整理します。単位制度の基本や学年別の組み方はラクロス部と単位の両立で扱っているため、ここでは欠席そのものへの対応を中心に解説します。

大学ごとの制度は大きく異なります。本記事では、公式サイトで確認できた2大学の例を紹介しますが、自分の大学の扱いは、必ず学則・履修案内・教務窓口で確認してください。

まず知っておきたい：「公欠」は大学や事由によって扱いが違う

「公欠」は、大学が定めた事由で授業を休んだときに、欠席として数えない（または配慮する）扱いを指す言葉として使われることが多いものです。ただし、何が対象になるか、配慮の中身は大学ごとに異なります。一般的には、次のような違いがあります。

論点大学による違いの例
部活の大会が対象か対象に含める大学もあれば、含めない大学もある
対象になる大会の範囲全国規模の大会のみ、など範囲を限定する場合がある
手続きの窓口学部の教務、学生課、授業担当教員など、大学ごとに異なる
配慮の中身出席扱い、証明書の発行のみ、教員の裁量など

つまり、「ラクロスの公式戦だから当然に公欠」とは限りません。以下に、公式サイトで確認できた2大学の例を挙げます。

公式情報で見る2大学の例

例1：立命館大学「試合等参加証明書」

立命館大学は、公式戦などへの参加で授業を欠席せざるを得ない場合に、大学が欠席の事情を証明する「試合等参加証明書」の制度を案内しています（出典: 立命館大学 アスリート支援「手続き」）。公式ページの記載から、押さえておきたい点は次のとおりです。

  • 証明書を提出しても、欠席が出席扱いや公欠扱いになるわけではなく、課題や小テストが自動的に免除されることもないと明記されています
  • 対象は、体育会本部の公認団体などに部員登録している学生で、対象大会は学生生活会議で承認された大会等（関西・西日本大会、全日本大会、国際大会など）とされています
  • 申請書類は、欠席が必要になる最初の授業日の3週間前までに提出するよう、厳守事項として示されています
  • 発行には通常1週間ほどかかり、即日発行はされないと案内されています
  • 申請書には部長（教員）または副部長（職員）の署名・捺印が必要で、監督やコーチの署名は認められないとされています
  • 欠席後の学修のフォローは、原則として学生自身が主体的に行うとされています

この制度から読み取れるのは、「大学が証明してくれる」ことと「授業の扱いが決まる」ことは別、という点です。証明書を持って教員に相談しても、配慮の中身は学生からの申し出と教員の対応に委ねられる部分があります。

例2：岡山大学「公欠・準公欠」と「欠席届」

岡山大学の公式ページでは、公欠・準公欠の事由として、気象警報・交通機関の運休、忌引き、感染症への罹患、裁判員制度に基づく出頭などが挙げられています。一方、課外活動（公認サークルの大会出場）は、公欠・準公欠にならない欠席として、欠席届を使う事由の側に掲載されています（出典: 岡山大学「公欠・準公欠について」）。

同ページでは、欠席届は授業担当教員に直接提出し、提出しても成績への配慮は教員の判断によるため確約はされない、と説明されています。公欠・準公欠届の提出先は所属学部の教務担当で、手続きの窓口が事由によって分かれている点にも注意が必要です。

2つの例から言えること

この2大学を並べると、同じ「大会で授業を休む」場面でも、対応の枠組みがかなり違うことがわかります。

  • 立命館大学のように、大会ごとに大学が証明する仕組みを持つ大学
  • 岡山大学のように、課外活動の大会は欠席届で教員に個別に相談する枠組みの大学

自分の大学がどちらに近いのか、あるいは別の仕組みなのかは、これらのページからは判断できません。入学時の履修案内や学生便覧、学部の教務窓口の案内で確認する必要があります。

試合が決まったら動く：欠席対応の流れ

ここからは、一般的に考えられる進め方を、時系列で整理します。大学の手続きに合わせて読み替えてください。

1. リーグ戦の日程と授業・試験の予定を並べる

まず、自分の地区の試合日程を確認し、授業の時間割・試験期間と並べます。試合日程は、関東男子の試合日程ページなど、本サイトの日程ページで確認できます。地区リーグの仕組み自体は大学ラクロスリーグ戦の仕組みで整理しています。

日程は、天候や会場の都合で変わる場合があります。試合日が変わる可能性があることも念頭に置いて、早めに動いておきたい項目と、直前に確定させる項目を分けておくと混乱しにくくなります。

2. 大学の制度で「対象になるか」「いつまでに」を確認する

立命館大学の例のように、申請に3週間前の期限がある大学もあります。試合の日程が公表された時点で、大学の制度に締切があるかを早めに確認することが大切です。確認する窓口の例は次のとおりです。

  • 履修案内・学生便覧（欠席や公欠に関する規定の章）
  • 学部の教務窓口
  • 学生課や体育会担当の窓口
  • 部の顧問教員・OB・先輩（過去の運用の実績を知っている場合があります）

先輩の話は参考になりますが、制度は年度で変わる場合があるため、最終的には大学の公式な案内で裏取りしておくのが安全です。

3. 授業担当の教員に、早めに自分の言葉で伝える

制度の有無にかかわらず、授業担当の教員へは早めに相談することが現実的な対応です。伝えるときは、次の項目を簡潔にまとめると、教員も判断しやすくなります。

  1. 欠席する日付と、対象の授業名
  2. 理由（大学リーグ戦の公式戦のため、など）と、日程が確認できる資料（大会要項・日程表など）
  3. 欠席する回に配布される資料や課題の扱いについての相談
  4. 可能であれば、事前提出や別日の対応が可能かの確認

「休むので配慮してください」ではなく、「この回に何をすればよいか」を一緒に確認する姿勢で話すと、やり取りが進みやすくなります。配慮の有無や内容は教員・大学の判断になる点は、岡山大学の例が示すとおりです。

4. 欠席した回の学修を、自分で補う

立命館大学の案内にも「学修のフォローは原則として学生自身が主体的に行う」とあります。実務的には、次のような方法が考えられます。

  • 同じ授業を履修している部員や友人に、ノートや配布資料を共有してもらう
  • 授業の資料がオンラインで配布される場合は、遠征の移動中に確認する
  • 欠席回の内容を、次回の授業前までに一度確認する

部員同士で同じ授業を取っている場合は、遠征で不在の人の分を、残る人が共有する流れを決めておくこともできます。

試験・レポートと遠征が重なったときの動き方

欠席の中でも、定期試験や課題の提出日と重なる場合は、影響が大きくなります。

定期試験の日と試合が重なる場合

定期試験と試合が同日になった場合の扱いは、大学によって異なります。追試験の制度がある大学もありますが、対象事由や手続きは決まっているため、試験の日程と試合の日程が重なる可能性がわかった時点で、教務窓口に相談するのが基本になります。岡山大学の公式ページでは、一部の科目群の定期試験の欠席は、欠席届ではなく受験延期願（追試験）の手続きによると案内されており、科目によって手続きが分かれる場合があることがわかります。

試合直前になってから相談しても、制度上、間に合わない場合があります。試験期間と試合期間が近づく学期は、履修登録の段階から意識しておくと動きやすくなります。

レポートの提出日が遠征中の場合

提出日が遠征中の場合は、提出方法（オンライン提出か、持参が必要か）を確認し、可能であれば事前に提出する方向で教員に相談します。遠征先でレポートを仕上げようとすると、移動・試合・宿泊の疲労で時間を確保できない場合もあるため、遠征の1週間前を目安に完成させる計画を立てておく方法もあります。

遠征の持ち物と一緒に学修物も準備する

遠征の持ち物は遠征・アウェイ戦の持ち物リストで整理しています。そこに、学修用の資料（タブレットや印刷物）、課題の締切一覧、提出に必要な機器の充電器なども加えておくと、移動中や宿泊先で対応しやすくなります。遠征費用の面はラクロス部の遠征費の考え方も参考にしてください。

履修の組み方で、欠席のリスクを減らす

欠席そのものを減らす方法として、履修登録の段階での工夫があります。一般的には、次のような考え方があります。

  • 出席が評価に含まれる科目の確認: シラバスで出席の扱い（毎回出席が必須か、欠席回数の上限があるか）を確認します
  • 試合期に重い科目を集中させない: リーグ戦が続く時期は、レポートや試験が集中する科目が重ならないように分散させます
  • 試合が多い曜日を避けた時間割: 土日が試合の中心でも、平日に遠征・合同練習が入る場合があるため、チームの予定を確認して組みます
  • オンデマンド型や録画視聴ができる授業の活用: 大学が認めている形式の授業であれば、出席の調整がしやすい場合があります
  • 集中講義や実習の日程確認: 夏季や冬季に行われる集中講義、実習は日程が動かしにくいため、リーグ戦の日程と早めに照らします

履修登録は期限が短く、後から変更できない場合もあります。リーグ戦の日程が出てから動くのでは遅いこともあるため、前年の日程を参考に、おおまかな試合期を想定して組む方法もあります。

チームとして決めておくとよいこと

個人任せにせず、チームとして最低限のルールを共有しておくと、欠席対応が楽になります。主将や幹部の立場の人は、次のような点を検討してみてください。

  1. 試合日程が出たら、部員全員が授業・試験の重なりを申告する: 申告の期限を決めておくと、スタメンや遠征メンバーの調整に早く入れます
  2. 大学の制度の締切をチームのカレンダーに入れる: 立命館大学のように3週間前が期限の制度がある場合を想定して、大学の窓口の案内を調べておきます
  3. 証明書類に必要な署名者を確認しておく: 立命館大学の例では、署名できる人が部長（教員）または副部長（職員）に限られるため、顧問教員の連絡先を把握しておく必要があります
  4. 授業を休む部員がいる回の連絡・フォロー役を決める: 同じ授業を取っている部員同士でペアを作る方法があります
  5. 引き継ぎで、毎年の手続きの流れを残す: 引き継ぎのやり方の記事も参考に、締切と窓口を文書にしておくと、代替わりでも続けやすくなります

シーズン全体の練習量の設計は、シーズン逆算の練習計画も参考になります。

困ったときの相談先

欠席や単位のことで悩んだときは、次のような窓口に相談できる場合があります。

  • 学部の教務窓口・履修相談窓口
  • 学生課・学生支援の窓口
  • 体育会本部や、部の顧問教員
  • 授業の担当教員（個別の配慮は教員の判断になることが多い）

一人で抱え込むと、欠席が重なって単位に影響する場合もあります。早めに相談すれば取れる選択肢が残っていることもあるため、不安を感じた時点で動くことをおすすめします。4年生は、就職活動との重なりも出てくるため、就活の年間スケジュールやインターンとの両立もあわせて確認しておくと、予定を組みやすくなります。

まとめ

  • 「試合だから公欠」とは限らず、大学や事由によって扱いが異なる
  • 立命館大学は大会ごとの証明書制度を案内しているが、出席扱いや課題免除は自動ではない（申請は3週間前が期限）
  • 岡山大学は、公認サークルの大会出場を欠席届の事由として掲載しており、配慮は教員の判断とされている
  • 試合日程が出たら、授業・試験との重なりを確認し、大学の制度と締切を早めに調べる
  • 教員には欠席日・理由・資料を添えて早めに相談し、欠席した回の学修は自分で補う

自分の地区の試合日程は試合日程ページ、チームの戦績は順位表や記録室で確認できます。日程が見えた段階で、まず自分の大学の欠席に関する案内を探すところから始めてみてください。
